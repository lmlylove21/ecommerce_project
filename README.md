# E-Commerce Data Analytics Dashboard

## Project Overview
This project analyzes e-commerce delivery data to understand revenue performance, delivery efficiency, customer satisfaction, refund behavior, and platform-wise order trends.

The dashboard was built in Microsoft Excel using pivot tables, pivot charts, KPI cards, conditional formatting, and data visualization techniques.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- KPI Cards
- Data Visualization

## Dataset
The dataset contains e-commerce order records with fields such as:
- Order ID
- Customer ID
- Platform
- Order Date & Time
- Delivery Time
- Product Category
- Order Value
- Customer Feedback
- Service Rating
- Delivery Delay
- Refund Requested

## Key Metrics
- Total Revenue
- Total Orders
- Average Delivery Time
- Average Service Rating
- Refund Percentage
- Delivery Delay Percentage

## Dashboard Features
- Revenue analysis by product category
- Orders comparison by platform
- Average delivery time by platform
- Refund request distribution
- Delivery delay analysis by platform
- KPI summary cards for quick business insights

## Data Cleaning & Preparation
- Converted the raw dataset into a structured Excel table.
- Used conditional formatting to highlight delayed deliveries and refund requests.
- Highlighted low service ratings to identify customer dissatisfaction.
- Created pivot tables for summary analysis.
- Built calculated KPI metrics for dashboard reporting.

## Key Insights
- Personal Care generated the highest revenue among product categories.
- Swiggy Instamart recorded the highest number of orders.
- JioMart had the highest average delivery time.
- Refund requests made up a significant share of total orders.
- Delivery delay percentage helped identify operational performance gaps.

## Project Outcome
This dashboard helps understand e-commerce delivery performance through business-focused KPIs and visual analysis. It can support decision-making related to platform performance, customer satisfaction, refund handling, and delivery efficiency.
